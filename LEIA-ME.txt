NICOVALBOLALIBRE V0.17.1
========================

NOVIDADES
- Ícone provisório do gato com VR no aplicativo, instalador, desinstalador e atalhos do Windows.
- O endereço do Cloudflare e a chave de leitura são configurados automaticamente no instalador.
- O Val só precisa instalar e abrir; não precisa colar endereço nem tokens.
- A publicação continua disponível somente no computador que tem a chave administrativa salva localmente.

PARA PUBLICAR A V0.17.1 NO GITHUB
1. No repositório, abra Settings > Secrets and variables > Actions.
2. Clique New repository secret.
3. Name: NVB_SYNC_READ_TOKEN
4. Secret: cole somente o valor da chave SYNC_READ_TOKEN (sem o nome da variável e sem sinal de igual).
5. Salve. Nunca cadastre SYNC_ADMIN_TOKEN no GitHub.
6. Copie os arquivos da V0.17.1 para a pasta local do repositório, faça Commit e Push origin.
7. Crie a tag v0.17.1 no commit novo e faça Push origin para enviar a tag.
8. O GitHub Actions compila e publica dist/NicoValBolaLibre-0.17.1-Setup.exe em Releases.

USO
- Nico: feche o app, instale a atualização sem apagar os dados do perfil e abra novamente. A chave administrativa local da V0.17.0 deve continuar disponível.
- Val: instale o mesmo Setup.exe e abra. URL e chave de leitura vêm pré-configuradas; não é necessário preencher nada.

SEGURANÇA
- O token somente-leitura é incorporado ao instalador para facilitar a conexão e poderá ser extraído por alguém com conhecimento técnico. Ele não permite publicar.
- SYNC_ADMIN_TOKEN nunca entra no repositório, no workflow, no instalador ou no computador do Val.
- O Worker Cloudflare deve ter as Secrets SYNC_READ_TOKEN e SYNC_ADMIN_TOKEN e o binding D1 DB.
- A API já configurada: https://nicoval-sync.tracker-mps.workers.dev

ÍCONE
O arquivo build/icon.ico usa o favicon atual de 64x64 como ícone provisório. Quando a imagem original em alta resolução estiver disponível, substitua build/icon.ico e publique uma nova versão.
