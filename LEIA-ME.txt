NICOVALBOLALIBRE V0.17.2
========================

NOVIDADES
- Bloqueia pop-ups/janelas abertas por players e páginas de terceiros.
- Bloqueia redirecionamentos externos que tentem substituir a janela principal.
- Links externos clicados na interface do aplicativo continuam abrindo no navegador padrão.
- Mantém navegações internas dos iframes dos players para não interferir no carregamento de vídeos.
- Inclui teste automatizado da proteção de navegação.
- Mantém o ícone do gato VR e a sincronização automática Cloudflare.

LIMITAÇÃO SOBRE BANNERS DENTRO DO PLAYER
A proteção não remove automaticamente anúncios desenhados dentro do próprio iframe do provedor (por exemplo, um banner/caixa com botão X). Regras genéricas poderiam esconder controles ou partes do vídeo. Esse tipo de elemento exige identificação e teste específico por provedor.

PARA PUBLICAR A V0.17.2 NO GITHUB
1. Copie os arquivos desta pasta para a pasta local do repositório, substituindo os antigos e preservando .git.
2. Confirme que NVB_SYNC_READ_TOKEN continua cadastrado em Settings > Secrets and variables > Actions.
3. Faça Commit e Push origin.
4. Crie a tag v0.17.2 no commit novo e faça Push origin para enviar a tag.
5. O GitHub Actions executa os testes e compila NicoValBolaLibre-0.17.2-Setup.exe.

CUIDADOS
- Nunca cadastre SYNC_ADMIN_TOKEN no GitHub nem inclua essa chave no instalador.
- Não remova os dados do perfil do aplicativo ao atualizar.
- O token compartilhado no instalador é somente de leitura.
